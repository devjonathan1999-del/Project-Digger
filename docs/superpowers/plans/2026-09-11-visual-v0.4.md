# Project Digger Visual v0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformer la vue Mine v0.3 en scène de jeu dominante, rétro-futuriste industrielle avec accents sci-fi profonds, sans modifier aucune règle de gameplay.

**Architecture:** `IndustryScreen` devient un shell compact (HUD, navigation, overlays et panneau contextuel flottant). `MineWorld` conserve caméra, positions, interactions et état d'animation, tandis qu'un nouveau `MineSceneRenderer` reçoit un état de présentation en lecture seule et dessine surface, galeries, machines, géologie et lumières. `IndustryGame` et `IndustrySession` restent inchangés.

**Tech Stack:** Godot 4.7.2, GDScript, `gl_compatibility`, contrôles Godot procéduraux, GitHub Actions/Xvfb.

**Spec:** `docs/superpowers/specs/2026-09-11-visual-v0.4-design.md`

## Global Constraints

- Ne modifier ni coûts, ni temps, ni rendements, ni progression, ni sauvegarde.
- Ne modifier aucune API publique de `IndustryGame` ou `IndustrySession`.
- Direction visuelle : 75 % rétro-futuriste industriel / 25 % sci-fi industriel sobre.
- À 1280×800, HUD ≤ 70 px et navigation ≤ 50 px.
- À 720×1000, aucun débordement horizontal et panneau contextuel en bottom-sheet.
- Les interactions existantes restent déclenchées via les zones de clic de `MineWorld` et les actions de `SitePanel`.
- Tous les tests v0.1/v0.2/v0.3 doivent rester verts.

- [ ] **Step 2: Créer `MineSceneRenderer` sans logique économique**

Interface exacte :

```gdscript
class_name MineSceneRenderer
extends Control

var surface_module_count := 0
var gallery_detail_count := 0
var deep_accent_strength := 0.0
var _state: Dictionary = {}

func set_scene_state(state: Dictionary) -> void:
    _state = state.duplicate(true)
    queue_redraw()

func accent_strength_for_depth(depth: int) -> float:
    if depth < 60: return 0.10
    if depth < 90: return 0.18
    if depth < 120: return 0.40
    if depth < 150: return 0.62
    return 0.82
```

Le renderer dessine : géologie, surface, galeries, rails/convoyeurs, supports, tuyaux, lampes, puits, modules d'extraction, foreuse, cristaux/anomalies.

- [ ] **Step 3: Faire de `MineWorld` le coordinateur**

`MineWorld` conserve zoom/drag, targets, timers et animation phase. Il construit un état de présentation uniquement en lecture :

```gdscript
{
  "depth": session.game.depth,
  "center_level": session.game.center_level,
  "mine_levels": session.game.mine_levels.duplicate(true),
  "discoveries": session.game.discoveries.duplicate(true),
  "permanent_sites": session.game.permanent_sites.duplicate(true),
  "jobs": session.game.jobs.duplicate(true),
  "scroll_depth": scroll_depth,
  "zoom": zoom,
  "animation_phase": animation_phase,
  "viewport_size": size,
}
```
